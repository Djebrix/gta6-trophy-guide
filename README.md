# GTA 6 Trophy Guide

An offline guide and tracker for all 55 GTA VI PS5 trophies (1 platinum, 2 gold, 6 silver, 46 bronze, 28 hidden).

## What it does

- Checklist of all 55 trophies with progress saved in localStorage.
- Export/import of your progress as a JSON file.
- Filters by kind (story, missable, collectibles, activities, online) and grade, plus text search.
- Spoiler setting that hides story trophy names and descriptions until you mark them earned.
- A roadmap to the platinum and missable flags built from the official trophy descriptions.
- A cited guide for every trophy: what to do, where and how, when it can be missed — each guide names and links its source.

## How to run it

Serve `app/` with any static server and open `app/index.html` in desktop Chrome. It works fully offline — nothing loads over the network.

## Note

The look is original work. No Rockstar logo, artwork, box art, or game screenshots are used.
